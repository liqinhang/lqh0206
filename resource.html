四.建议

1、学习心态与效率提升

  • 1. ❌ 避坑：只看不敲

    • 指南： 不要只是观看教程视频或阅读代码。请手动输入每一个代码块，即使是复制粘贴，也要在粘贴后理解并运行一次，确保能复现结果。

  • 2. ❌ 避坑：害怕报错

    • 指南： 报错是学习的一部分！ 遇到错误，请先认真阅读最后一行错误提示。不要直接截图问人，要学会将关键的英文错误信息复制到 Google/Baidu 搜索。

  • 3. ✅ 技巧：立刻学习 Git

    • 指南： 无论代码量多少，都请将您的每一个练习项目放入 Git 进行版本控制。这不仅能保存您的代码历史，也是未来工作必备技能。

  • 4. ✅ 技巧：多用 IDE 功能

    • 指南： 充分利用 VS Code、PyCharm、IntelliJ IDEA 的自动补全、格式化代码、快速重命名等功能。它们可以帮助您避免低级语法错误，并养成良好的编码习惯。

  • 5. ✅ 技巧：合理利用 AI 辅助

    • 指南： AI 工具是强大的辅助，但不要将其作为主要答案来源。让 AI 帮你解释代码、重构逻辑或查阅 API，但避免让 AI 代写整个项目，要保持自己对代码的控制权和理解。

2、日常代码管理与习惯

习惯/工具 建议操作 复制要点
代码注释 及时、清晰地注释为什么这么做，而不是这段代码在做什么。 # 这是为什么... 而不是 # 这是加法
命名规范 变量和函数名要具有描述性，避免使用 a, b, c 或拼音。 user_name, calculate_price()
提问技巧 提问时，附上：1. 想做什么，2. 遇到的问题，3. 错误提示，4. 您的代码。 提问前先准备 MRE (Minimal Reproducible Example)

五.教学篇---C++基础

C++ 编程语言

C++ 是由比雅尼·斯特劳斯特鲁普（Bjarne Stroustrup）开发的最常用和最受欢迎的编程语言。C++ 是一种高级的面向对象编程语言。这种语言允许开发者编写干净且高效的代码，用于大型应用程序和软件开发、游戏开发以及操作系统编程。C++ 是对 C 编程语言的扩展，加入了面向对象编程（OOPs）的特性，并用于开发计算机程序。这个 C++ 教程将涵盖从基础到高级的所有 C++ 主题，如 C++ 基础、C++ 函数、C++ 类、面向对象编程（OOPs）和 STL 概念。

  • C++ 是最常用和最受欢迎的编程语言之一。
  • C++ 被用于开发操作系统、嵌入式系统和图形用户界面。
  • 它是一种面向对象的编程语言，实现了所有面向对象编程（OOP）的概念，如抽象、封装和继承，这些特性为程序提供了清晰的结构，并允许代码重用，从而降低开发成本并提供安全性。
  • 它是可移植的，可以用来创建适应多种平台的应用程序。
  • C++ 容易学习，因此你可以选择它作为你的第一个编程语言。
  • 由于其语法类似于 C、Java 和 C#，它使得程序员在切换到 C++ 时变得容易。
